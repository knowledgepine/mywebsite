# junsongzhao.com

Personal site for Junsong Zhao, designed to publish directly on GitHub Pages.

## Local preview

This first version uses plain HTML and CSS, so no build step is required. Open `index.html` in a browser, or run a local static server from this directory.

## Publish with GitHub Pages

1. Push this directory to a public GitHub repository.
2. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
3. Once the default `github.io` URL works, add `junsongzhao.com` as the custom domain.
